# 突击莉莉桌宠 (LilyPet)

基于工作区 Spine 骨骼素材制作的 Windows 桌面宠物。角色会待在桌面角落，会说话、表演动作、睡觉，并配有完整的表情系统。

## 运行

```bat
npm install
npm start
```

也可以直接下载 **Release** 里的安装包或免安装压缩包使用。

## 玩法与功能

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 按身体部位回应（摸头/胳膊/肚子/腿有专属台词与反应） |
| 左键双击 | 随机切换表情 |
| 按住左键拖动 | 移动宠物位置（位置会被记住） |
| 右键 | 打开功能菜单 |
| 自动行为 | 每隔一段时间随机表演动作/说话；长时间无人理睬会睡觉（点一下唤醒） |
| 连续打字 | 梨璃：打字好快呀 / 是在写作战报告吗…（睡觉时会被"吵醒"） |
| 连续点击鼠标 | 梨璃：手速不错嘛 / 要跟梨璃比试吗… |
| 持续滑动鼠标 | 梨璃：鼠标滑来滑去在找什么呀… |
| 电脑 CPU 高占用 | 梨璃：电脑有点吃力 / 风扇好大声… |
| 播放视频/音乐 | 梨璃：在看视频吗 / 在听歌呀（音乐与视频台词不同；停止播放也有回应） |
| 📊 记数模块 | 角色旁独立小卡片，显示键盘敲击次数（今日/本周/本月/总计，菜单切换） |

> 场景互动（打字/点击/滑鼠/CPU/媒体）由 `tools/sensor.ps1` 感知，**可在托盘菜单或功能菜单 🎭 场景互动 中整体开关**。

### 右键菜单

- **独立菜单窗口**：菜单显示在*单独的窗口*，默认出现在角色*左侧*（放不下自动翻到右侧），角色窗口位置完全不动、无闪烁
- **毛玻璃圆角卡片**：半透明深紫主题 + 樱粉强调色，圆角气泡造型 + 柔和阴影
- **主菜单 → 二级面板**：
  - **🎭 动作**：表情（22 种实时切换）/ 动作（预设表演）/ 动画（全部 33 个，支持搜索）
  - **✨ 状态**：当前表情·动画 / 描边模式（F10）/ 边界调试（F9）
  - **💬 交互**：场景互动 / 鼠标穿透 / 总在最前
  - **⚙️ 设置**：大小（小/中/大）/ 开机自启
  - **🌙 休息**：隐藏到托盘 | **🚪 退出**：二次确认防止误触
- **鼠标穿透**：整个宠物都不挡鼠标，点击直达下方窗口；可用托盘菜单临时交互
- **✏️ 描边模式**：仅角色本体可交互，透明区域点击穿透（默认开启，F10 开关）
- **🎭 场景互动**：感知连续打字/点击/滑鼠/CPU/媒体，梨璃会说出对应台词并做表情动作（带冷却去重）

## 台词配置（外部文件，免改代码）

所有发言都在 `renderer/lines.jsonc` 里按"场景编号"维护，改台词只需编辑该文件：

- 每个场景是一个编号键，值为发言数组，桌宠随机挑选
- 支持 `//` 行注释与 `/* */` 块注释
- 编号规则：`01~09` 通用场景 | `10~19` 场景互动 | `20~29` 身体部位
- 场景配套动作在 `motions` / `partMotions` 中配置（fun/anger/shy/surprise/think/positive/negative，写错自动回退）
- **容错**：文件缺失/键缺失/数组为空/格式错误 → 自动回退程序内置台词
- 修改保存后**重启桌宠生效**

> 安装包版：桌宠首次启动会自动把默认台词复制到 `%APPDATA%\突击莉莉桌宠\lines.jsonc`，之后优先读取这份外部文件。

## 素材来源

- `renderer/assets-v1/CharacterJobSpine010001001.skel` — Spine 3.6.53 二进制骨骼（74 骨骼 / 97 槽位 / 33 动画）
- `renderer/assets-v1/CharacterJobSpine010001001.atlas` + `.png` — 2048×2048 图集
- `renderer/assets/CharacterJobIconM0001001.png` — 托盘图标

## 技术说明

- **Electron** 透明无边框置顶窗口 + **PixiJS 5.1.3** WebGL 渲染
- 加载管线：`spine-skeleton-binary.js` 将 `.skel` 二进制解析为 JSON，站点原版 `pixi-spine.umd.min.js`（内含 spine37/spine38 运行时）解析图集与骨骼
- 表情系统：24 表情 = 眉 + 嘴 + 眼组合，嘴部说话每 180ms 循环，眨眼每 5s±2s
- **场景互动传感器**（`tools/sensor.ps1`）：主进程启动一个 PowerShell 进程感知用户场景，零原生依赖（`user32` 轮询 / `ntdll` CPU 信息 / WinRT SMTC 媒体会话）
- 单击身体部位：渲染进程按模型像素包围盒分区（头部/左臂/右臂/躯干/腿）
- 描边交互：默认开启，透明区域点击穿透到下层窗口，主进程每 100ms 轮询真实光标位置驱动

## 目录结构

```
├── main.js               # Electron 主进程（窗口/托盘/配置持久化/调试截图）
├── preload.js            # 安全桥接
├── renderer/             # 页面、样式、逻辑、素材、站点原版库
│   ├── pixi-spine.umd.min.js  # 站点原版 pixi-spine（含 spine37/spine38）
│   ├── spine-skeleton-binary.js  # 站点原版 .skel→JSON 转换器
│   ├── lines.jsonc       # 台词配置（JSONC 格式）
│   ├── assets-v1/        # v1 立绘素材
│   └── themes/           # 主题样式
├── vendor/spine36/       # 旧引擎运行时（仅工具使用）
├── tools/                # 检查/渲染测试/调试脚本（含 sensor.ps1 场景传感器）
└── build/                # 打包资源（图标）
```

## 调试

```bat
npm run debug:menu     # 打开菜单截图验证
npm run debug:menutest # 自动点击菜单项，验证点击链路
npm run debug:react    # 点击反应
npm run debug:sleep    # 睡眠模式
npm run debug:talk     # 说话模式
npm run debug:emotion  # 切换 Anger 表情
npm run debug:motion   # 播放 Fun 动作
npm run debug:bounds   # 边界调试（模型范围/可触控区域）
npm run debug:outline  # 描边模式
```

截图保存为工作区根目录 `debug-*.png`。渲染进程日志写入 `debug.log`（仅调试模式）。
