# 突击莉莉桌宠

使用了vibe coding，美术素材来源于手游——突击莉莉lsbl

基于 Spine 骨骼素材制作的 Windows 桌面宠物。角色会待在桌面角落，会说话、表演动作、睡觉，并配有表情系统。

直接下载 **Release** 里的安装包或免安装压缩包使用。

## 玩法与功能

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 按身体部位回应 |
| 左键双击 | 随机切换表情 |
| 按住左键拖动 | 移动宠物位置 |
| 右键 | 打开功能菜单 |
| 自动行为 | 每隔一段时间随机表演动作/说话；长时间无人理睬会睡觉（点一下唤醒） |
| 连续打字 | 梨璃：打字好快呀 / 是在写作战报告吗…（睡觉时会被"吵醒"） |
| 连续点击鼠标 | 梨璃：手速不错嘛 / 要跟梨璃比试吗… |
| 持续滑动鼠标 | 梨璃：鼠标滑来滑去在找什么呀… |
| 电脑 CPU 高占用 | 梨璃：电脑有点吃力 / 风扇好大声… |
| 播放视频/音乐 | 梨璃：在看视频吗 / 在听歌呀（音乐与视频台词不同；停止播放也有回应） |
|  记数模块 | 角色旁独立小卡片，显示键盘敲击次数（今日/本周/本月/总计，菜单切换） |

### 右键菜单

- **菜单窗口**：菜单显示在*单独的窗口*，默认出现在角色*左侧*（放不下自动翻到右侧）
- **主菜单 → 二级面板**：
  -  动作：表情（22 种可切换）/ 动作（预设表演）/ 动画（全部 33 个）
  -  状态：当前表情·动画 / 描边模式（F10）/ 边界调试（F9）
  -  交互：场景互动 / 鼠标穿透 / 总在最前
  -  设置：大小（小/中/大）/ 开机自启
  -  休息：隐藏到托盘 | ** 退出**：二次确认防止误触
- **鼠标穿透**：整个宠物都不挡鼠标，可点击下方窗口；可用托盘菜单临时交互
-  描边模式：仅角色本体可交互，透明区域点击穿透（默认开启，F10 开关）
-  场景互动：感知连续打字/点击/滑鼠/CPU/媒体，梨璃会说出对应台词并做表情动作（带冷却去重）

## 台词配置

- 每个场景是一个编号键，值为发言数组，桌宠随机挑选
- 可以在设置中自行设置、添加
- 修改保存后**重启桌宠生效**
